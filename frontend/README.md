# ShopKart — Frontend

React 19 + Vite single-page app (React Router, Axios, Redux Toolkit).

See the [root README](../README.md) for setup. From this folder: `npm install`, `npm run dev` (http://localhost:5173), `npm run build`, `npm run lint`.
API calls go through `src/services/api.js`; Vite proxies them to the backend on port 5000 (see `vite.config.js`).
